6. Aggregation

The DB now holds one row per detected vehicle pass. Export rolls those rows up into the TMC Excel format traffic engineers consume — 15-minute intervals, per leg, per movement, with hard-coded integers (no formulas).

From per-event rows to per-bucket counts

What the Excel file contains

backend/services/excel_export.py emits a workbook with three sheets, all integers, no formulas (PRD constraint):

Sheet 1 — TMC Summary

Totals over the processed window. One row per leg, a column per movement plus a row total — the high-level "how many turned each way" answer, broken down by FHWA vehicle class.

Sheet 2 — Time Series

One row per 15-min bucket, total vehicles in that bucket — so engineers can see peaks-within-peaks (the 7:30 surge vs the 7:00 trickle).

Sheet 3 — Raw Events

Every vehicle_events row: timestamp, origin leg, movement, class, confidence, frame, manual-edit flag. Used for QA, sampling, and debugging misclassifications.

Cross-camera dedup

When an intersection-day has multiple cameras with overlapping coverage, the v3 aggregator collapses parallel-overlap duplicates before counting: two events from different cameras in the same time window and the same (origin, movement) bucket within tolerance are treated as one physical vehicle.

Trim filtering & manual overrides

Trims are wall-clock windows scoped to the intersection-day ("process 7–9 AM and 4–6 PM, skip the rest"). Events outside any active trim are excluded from export but kept in the DB. Manual review in the dashboard can reject an event (rejected=1, excluded) or re-label it (manually_edited=1, new label wins). Both states are exported in Sheet 3 so the audit trail is preserved.

Validating the count

Aggregated counts are checked against the Miovision per-minute origin→destination matrix (the same ground truth that gates the path bank), via scripts/od_accuracy.py. The headline number is net error at TMC granularity — how far each 15-minute per-movement count is from Miovision — because that's what the deliverable reports. The full methodology, and the machinery for driving the error down, is the next page.
