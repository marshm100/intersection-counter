0. Overview

What this app does, and the shape of the work it performs end-to-end. Replaces commercial tools (GoodVision, Miovision) with a local-only Python pipeline.

What it produces

Input: one or more video files from a fixed camera looking at an intersection.
Output: a TMC (Turning Movement Count) Excel sheet — for each 15-minute interval, for each approach leg, the number of vehicles that turned left / went through / turned right / made a U-turn, broken down by FHWA vehicle class.

Data model (v3)

The pipeline at a glance

From a video file to a TMC count, the pipeline runs these stages per camera, per clip:

1 Preprocess — adaptive: histogram correction for low-light frames, no-op otherwise.
2 Detect — YOLO finds vehicle bounding boxes per frame; detections are cached so later experiments retrack without re-detecting. Page 2.
3 Track — ByteTrack or BoT-SORT associates same-vehicle detections across frames into track_ids (the tracker is picked per camera by measurement).
4 Accumulate trajectory — append each frame's bbox center to the track's point list.
5 Match the path bank — a joint partial-Fréchet scorer matches the trajectory against the camera's learned road polylines. Page 3.
6 Read origin + destination + movement off the matched path — origin is read off the path, not guessed from the entry tangent. Pages 4–5.
7 Persist event — write one row to vehicle_events with trajectory, origin, movement, timestamps.
8 Aggregate — at export time, bin events into 15-min windows and write the TMC Excel. Page 6.

Stages 5–6 are the heart of the current ("v3") pipeline: instead of attributing each vehicle from a single calibrated point + heading, the system learns the actual shape of every road through the intersection — the path bank — and matches whole trajectories against it.

Hard constraints

  • Frontend: vanilla HTML/CSS/JS — no React, no npm, no build step.
  • Database: raw sqlite3 — no ORM.
  • Turn classification: trajectory shape — no exit zones, no turn matrix.
  • Excel: hard-coded integers — no formulas.
  • Processing: never stops for a single-frame error.
  • Runs entirely locally — no cloud, no auth, no internet required after install.
  • Pedestrians are out of scope for v2.
