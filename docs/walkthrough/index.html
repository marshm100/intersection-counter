Walkthrough

Nine static pages that explain what the app does and how each pipeline stage works — from a raw traffic video to a Turning-Movement-Count spreadsheet. Built for self-review, with concrete diagrams anchored on the real Sunnyvale TX corridor so the math has something to stand on.

  1. 0. Overview — what it produces, the data model, the pipeline at a glance
  2. 1. Calibration — legs, origin points, reference headings, tripwires
  3. 2. Detection & Tracking — YOLO + the detection cache + ByteTrack / BoT-SORT
  4. 3. The Path Bank — learned road geometry: data-driven polylines from real tracks + Miovision OD
  5. 4. Origin & Attribution — the joint partial-Fréchet scorer that reads origin off the matched path
  6. 5. Movement Classification — destination leg + left/through/right/U-turn from trajectory shape
  7. 6. Aggregation — events → 15-min buckets → TMC Excel
  8. 7. Accuracy & Validation — measuring vs Miovision, and the snap-magnet / recovery defenses
  9. 8. The Corridor — five cameras, one arterial: multi-camera generalization
The diagrams use the Sunnyvale TX study (project 97a7849a) — a five-intersection corridor along N Belt Line Rd, one camera each. Frames are 640×480. The single-camera examples use camera 1 (Belt Line & Northwest Dr), a four-leg intersection; the four legs, by cardinal approach:
  • L22 NB N Belt Line Rd — origin (495, 218), ref 262.5°

The four-way example (page 7–8) uses camera 5 (Belt Line & Barnes Bridge Rd), legs L36–L39 (W/S/E/N).
